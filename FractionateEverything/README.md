# 万物分馏 Fractionate Everything

万物分馏是一条需要探索、解析和供养的古文明生命工业路线。从母星遗迹和基础矿物复制起步，逐步建立珍奇催化、生命塔培育、原胚繁育与工业置换产线。

Fractionate Everything is a living-industry progression built around exploration, sample analysis and sustained automation. Begin with a relic on your home world, then develop five specialized fractionators and a galaxy-wide subspace inventory.

## 从哪里开始 Getting Started

开局的G手册会出现“神秘信号？”。首遗物位于出生点所在半球，与出生点保持一段探索距离，并避开黑雾基地。探测器初始跟踪文明信标，四挡依次给出星系、星球、经纬度区间和近距离强度；区域挡同时显示玩家自身坐标。100%是取整后的读数，实际进入范围才会回收；步行与悬浮均可回收。关键信号的回收结果会打开确认弹窗。首遗物提供：

- 基础矿物塔4座、基础解析塔2座及其制造配方。
- 铁、铜、石、煤四条解析线索，以及一条原胚培育线索。
- 分馏亚空间和主面板访问。
- 完整机械骨骼步行升级链及当前科技附带效果，包括星环的生命上限奖励；已完成等级不会重复授予。

普通矿物配方需要先解析，不直接解锁。首次实际生产电磁矩阵后，新的主线才会带来高级交互塔2座、原胚60个和源点30份。先给高级塔供养矩阵，再着手培育。

The starting relic appears in the birth hemisphere, away from dark-fog bases. Recover it for four Basic Mineral Towers, two Basic Analysis Towers, sample clues and the full Mechanical Frame walking-upgrade chain, including any additional effects provided by compatible mods. Analyse the ordinary minerals before replicating them. Producing the first Electromagnetic Matrix opens the story supply of living towers, embryos and Memory.

## 五种塔 Five Fractionators

| 塔型 | 用途 |
| --- | --- |
| 基础矿物塔 / Basic Mineral | 自动匹配已解析普通矿物配方，成功时同物1变2 |
| 基础解析塔 / Basic Analysis | 解析线索指定样本，失败回流；持续投入科学矩阵可扩充亚空间 |
| 高级矿物塔 / Advanced Mineral | 使用普通矿物与珍奇催化剂增殖资源 |
| 高级交互塔 / Advanced Interaction | 培育高级塔，以塔体模板繁育原胚 |
| 高级转化塔 / Advanced Conversion | 置换指定燃料或机器，并回收部分部件 |

基础塔独立制造、接入电网，正面接口还能上传到亚空间。高级塔在窗口选择已解析配方，使用矩阵作为营养。正常产物和失败物等待当前集装规格输出；主消耗物不足一轮后释放尾料，剩余催化剂不会让尾料永久滞留。

矩阵越高级，每件营养越多，处理速度也越高。生命塔工作和待机都会消耗营养；断粮后逐渐损失耐久，充分供养可以恢复。无人机不能维修生命塔，主动拆除返还缓存，损毁则丢失缓存。每类缓存按20堆计算，实际件数随全局堆叠变化。

Basic towers use electricity. Advanced towers consume matrices as nutrition and must be kept fed. Dismantling returns cached items; destruction does not. Buffers hold twenty current cargo stacks.

## 研究与源点 Research and Memory

探索只告诉你需要什么样本，结果的名称与用途在解析完成前保持未知。面板只列已知且未完成的样本，完成后移出。同一样本共享进度，完成时从已探索未完成的记录中取得一项。解析成功才消耗样本，大多数样本会完整回流，可以用传送带连接成循环。培育使用原胚，反向繁育使用对应塔体。

源点每个矩阵阶段恢复一次成长科技资格，随后仍需用矩阵逐项研究。成长科技的科研工作量参考原版同矩阵阶段升级，矩阵成本单独计算；未显现科技不能加入研究队列。物流科技则在原版物流资格之后，通过回收远古接口恢复。

同种高级塔亚空间库存首次达到1000，会让对应特质线索有机会出现；首次千塔还会出现献祭主线。回收后，解析塔在没有待解析内容时才献祭塔体，以2%概率产源点。

当前可恢复阶段全部完成后，可继续向解析塔投入源点。本完整分钟的投入提高下一分钟三类高级塔的成功率：相对增益为 `min(75%, 5%×floor(sqrt(M)))`，M是本分钟实际献祭的源点。增益每分钟替换，不永久累积；源点生产变体独立消耗，不会被自动截流。

Each sample has one shared probabilistic analysis slot. Memory restores growth qualifications once per matrix stage. After the sacrifice story is unlocked, excess tower samples can produce Memory; Memory offerings then boost all advanced towers during the next complete minute.

## 遗迹与广播 Exploration

静默遗迹位置和质量固定，红糖、黄糖会开放更深层的地点；已回收点不刷新。母星岩石星共有40处，出生星系其他岩石星每颗30处，外星系每颗24处，气巨仅少量悬空点。统计只覆盖当前星球和星系的已开放静默点。

首遗物后普通广播持续产生，初始周期10分钟，探索科技逐渐缩短。广播质量取决于生成时的矩阵阶段，此后不升档。蓝红阶段集中在母星，黄糖扩展到本星系，具备曲速能力后再进入邻近星系。

探测器有“文明信标”和“异常探索”两种模式，首遗物后开放探索模式。Alt+R切换星系、星球、区域、精细四挡，Alt+T切换模式，可在游戏键位设置中修改。换挡保留当前目标，回收后自动续接。文明信标沿用古代仪器；探索模块来自仿制，第二页的探索成长科技逐步修复与校准它。区域格按星球真实半径换算，同样适用于GalacticScale的大星球，不会因为半径增大而要求绕球盲搜。
精细挡在180米局部范围内显示最接近的信号档位，例如20%精度下91%显示100%；“已定位”仍以实际到达判定为准。HUD复用原版白字黑边样式，随黑雾列表与教学面板动态避让，在全屏界面隐藏。普通遗迹18米、关键地点30米为水平回收范围，空间距离计入悬空点位的高度，使步行和默认悬浮均可触发，岩石星球和气巨使用同一规则。实际奖励保存在地点档案，查看时按当前语言生成文本。已收到的广播和主线可在信号追踪页查看，隐藏静默点不会提前列出。探索成长五级后可主动标注位置，但不会启动移动。

首个矩阵生产后，亚空间原胚或高级交互塔不足300时，资源点有机会补给对应物品。原胚也可通过黑雾战斗补充。黑雾击杀的残片基础掉率为10%，每级探索再增加2个百分点；每片残片送入解析塔后有2%概率生成新广播。战斗不是主线门槛。

Silent relics have fixed locations and open in layers. Dynamic broadcasts continue indefinitely and keep the quality rolled when generated. Alt+R cycles the detector through system, planet, region and fine ranges; Alt+T switches civilization beacons and exploration. The region range shows coordinate bounds and your position, with search areas scaled to the planet's actual radius. Fine readings round to the nearest step: 100% does not itself confirm arrival. Recovered rewards are recorded without rerolling. Combat is optional.

## 亚空间与成长 Subspace and Progression

亚空间是跨星球共享库存，每种物品独立计容量。低价原料按价值获得更大额度，铁矿等普通原料初始可存10000件；建筑和未知估值物品保留10组基础额度。仓储页显示全局容量倍率，鼠标悬停物品可查看其库存和容量。普通上传满仓拒收，探索奖励可超额且仍能提取。

向已供电的基础解析塔侧面持续投入科学矩阵，即可永久扩容。全部塔共享供料，每秒最多使用一件，优先高档矩阵，每档最多预存60件；剩余输入保留增产点回流。蓝至白效率依次为1、2、4、8、16、32倍，容量越大增长越慢；多塔与集装只改善供料稳定性，停供不丢失已有容量。

手动存取和基础塔正面上传无额外耗能。行星/星际物流交互站自动存取，保留槽位模式、阈值、增产点、蓝图与复制粘贴；按物品价值和实际搬运量消耗站内电量。

保留两条堆叠路线：普通路线在自动集装机或集装分拣器任一主配方前置科技研究完成后获得4堆叠（原版为黄糖阶段），紫8、绿12、白16及20；兑换配方提前允许制造设备不会直接开放堆叠。集装分拣器的双向运输仍需玩家单独研究。已完整体验过的档案从蓝糖4开始，红8、黄12、紫16、绿20。全局堆叠同时影响缓存、输出和原版配方时间。白糖重复升级合并在科技树第六列，终极科技位于第七列，解锁区显示每一级增加的能力。

探索常规十级完成后开放终极探索任务；亚空间容量达到初始的35倍后开放终极仓储任务。恢复中继或空间锚点，分批明确交付2400源点，再连接最终核心；任务直接授予终极科技，无矩阵研究费用。终极探索持续补足五个普通广播，终极仓储解除玩法容量限制。

Each item has its own subspace capacity, with larger allowances for inexpensive materials. Feed science matrices into the side of a powered Basic Analysis Tower for permanent expansion. All towers share a limit of one matrix per second, prioritizing higher tiers; larger storage expands more slowly. Hover over an item on the storage page to see its capacity. Exploration level ten and a storage multiplier of 35 unlock their respective ultimate quests. Each requires a 2,400-Memory delivery. Ultimate exploration replenishes five ordinary broadcasts; ultimate storage removes the gameplay capacity limit.

## 高级配方 Advanced Recipes

高级配方基础成功率20%，失败主消耗物回流，催化剂只在成功轮概率消耗。目录包含珍奇增殖、三种塔的培育与繁育、两种燃料置换和采矿机/熔炉重构。

单极磁石基础配方使用多种矿物及少量单极催化，不消耗源点。白糖阶段还有独立的源点简化变体；两条路线可以并存。

Advanced recipes include rare-resource catalysis, tower cultivation and breeding, fuel replacement and machine reconstruction. The mineral-based monopolar-magnet recipe and its later Memory-consuming variant coexist.

面板分为指引、研究、探索、工业、手记、设置，共十七页。默认当前目标，指南随发现开放；左侧是窄单列目录，右侧是宽阅读区，点击切换内容，长文可以滚动。G手册只在关键节点提供短篇故事，具体操作请看面板指南。中文物品名为“源点”“残片”。高级塔配方在塔窗口选择，窗口区分缺少矩阵、缺料、堵塞和集装。

Keys can be changed in the game settings. The panel has seventeen pages across six categories, starting with Current Goals and a stage-based guide.

## 联机与存档 Multiplayer and Saves

Nebula由主机结算研究、探索、交付、库存和高级塔，中途加入同步当前状态。客户端认领或交付时，主机按连接数据验证玩家位置、所在星球、回收距离和剩余需求；回收事实传给客户端，由各端使用自己的语言显示。客户端请使用传送带提取高级塔产物。

当前FE存档格式为13，面向新存档。联机所有玩家必须使用相同FE版本。只有正常游玩、取得三类高级塔并达到20堆叠的合格存档，才能写入“已玩过分馏3.0”标记；沙盒、用过一键解锁，以及没有资格记录的早期存档均不能新写入该标记。既有本地标记不会被重置。

The current save format is version 13. Nebula is host-authoritative; all players must use the same FE version. Sandbox saves, saves using unlock-all and earlier saves without an eligibility record cannot grant the cross-save completion flag.

## 安装 Installation

推荐使用 [r2modman](https://dsp.thunderstore.io/package/ebkr/r2modman/) 或兼容的Thunderstore管理器安装并启用FractionateEverything。清单已声明BepInEx、LDBTool、DSPModSave、CommonAPI、BuildBarTool、ModFixerOne、ErrorAnalyzer和NebulaMultiplayerModApi依赖。

Install with r2modman or another Thunderstore-compatible manager. Required dependencies are declared in the package manifest.
