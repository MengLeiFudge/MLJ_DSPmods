# Logic/Station — 物流交互站域

本域负责行星/星际物流交互站原型、槽位模式、亚空间传输、建筑参数和原版物流站界面补丁。

## Structure

```
Station/
├── Definitions/             # 行星与星际物流交互站
├── StationManager.cs        # 翻译、配置、槽位模式存档聚合
├── Runtime.cs               # 阈值、部分传输、耗能与库存接线
├── ModeState.cs             # 上传/下载独立开关及旧模式编码
├── StationParameterPatch.cs # Q 复制、复制粘贴、蓝图参数
├── WindowPatch.cs           # 单站窗口
├── ControlPanelPatch.cs     # 物流总控面板
└── OutputStackPatch.cs      # 输出堆叠投影
```

## Rules

- 站点运行语义只放 `Runtime`；窗口文件只读写公开模式/设置接口。
- 亚空间数量与增产点归 `DataCenterInventory`，本站不得维护镜像余额。
- 主机运行自动传输。有限上传以min(单物品容量,上传目标)为界；无限上传允许超额折算扩容价值，扣槽位的数量包含实际入库和折算部分。拒收物品及增产点按StorageReceipt原样留站，不自行重新推算。
- 下载保留亚空间中的真实增产点，不创建自动喷涂池。
- 仅向本轮有实际存取需求的槽位均分一次电量，复用请求缓冲；不进行多轮再分配。每槽按预算和单件耗能裁剪数量，最终只按实际搬运件数扣电。
- 单件能效、充电与储能倍率统一由 `GrowthTechnologyManager` 投影；本站不另存科技等级。两种交互站按对应原版塔基础参数应用电力倍率，不叠乘已有加成；提高上限不补充电量。
- 右上上传、右下下载独立控制，双关槽不参与自动存取；左侧原版物流供需独立。联机由主机合并方向设置并广播。旧传输/容量编码和新增Disabled状态必须继续支持 Q 键复制、复制粘贴、蓝图与旧物流站升级路径。
- 输出堆叠使用全局 `StackingManager` 状态，不维护站点等级或单站强化。
- 塔厂与扩容兼容读取实际storage长度，不写死槽数；分页复用的行控件按钮使用固定名称，读写当前index，切换绑定时关闭旧槽弹窗。机器、产品及原料由玩家配置，不自动替换模式。
- 玩家可见文本使用“亚空间”；内部 `DataCenter` 标识可保留以维持稳定合同。
