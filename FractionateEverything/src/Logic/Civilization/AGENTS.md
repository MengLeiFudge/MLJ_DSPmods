# Logic/Civilization — 生命工业研究与探索域

本域拥有具体内容发现、阶段恢复、分钟献祭、遗迹任务、成长科技投影和本地完成标记。玩法与参数真源分别为GAME_DESIGN及GAME_DESIGN_SPEC，不在此复制数值表。

## 归属与入口

- CivilizationManager.cs：主线程tick、提示队列、文明子块与同步调度。Tick 挂在 Unity Update，低帧率时两次调用之间 gameTick 会跳刻；按秒和按 10 刻的逻辑必须按序号变化触发，不得用 `gameTick % N == 0`。
- ResearchCatalog.cs：原型加载后构造的只读内容定义、样本索引与方向关系；不持有存档进度。
- ResearchManager.cs：共享槽、已探索/解析内容、塔体里程碑及运行快照；重建目录后在既有研究锁内刷新候选缓存。
- ResearchProgression.cs：矩阵阶段资格、实际Memory投入、分钟窗口和献祭开放状态。
- ExplorationManager.cs：静默几何、动态广播、主线、终极任务、探测候选和实际回收记录。
- ExplorationDelivery.cs：到地真实背包交付、差额提示和持久流水；联机库存衔接由MemoryDeliverySync负责。
- ExplorationDiscovery.cs：主机发现账本、活动范围及连续信号强度；已发现地点保存完整坐标。
- ExplorationDetector.cs：本地邻近信号投影及玩家发起的原版导航，首遗物不公开坐标。
- GrowthTechnologyManager.cs：两页科技定义、唯一堆叠路线、阶段身份、等级与效果投影。
- MatrixResearchCosts.cs：从最终参考科技读取材料比例与成本，阶段身份不从材料反推。
- TechnologyTreePatch.cs：FE科技显示、解锁文本及原版科技树接线。
- Recovery.cs：首遗物、亚空间通信与基础塔启动补给。
- FragDropPatch.cs：可选黑雾补给。
- PermanentProfileStore.cs：本地完成世界账本及去重通关次数。
- MetadataExtraction.cs：只读生产峰值、共享提取额度及跨星图倍率。
- Monument/：矩阵帆身份、丰碑建设与解析账本、原版发射器专属弹药分流、接收站共享预算；普通配方时间由VanillaRecipeManager投影。
- Tutorial.cs：关键发现触发的G手册短篇叙事及第三方布局兼容；详细操作归面板指南。

## 状态边界

- 原版GameHistoryData拥有科技完成状态；首遗物只建立基础塔与亚空间访问，终极任务在终点授予终极科技，不另存等级。
- Civilization3聚合Research、Exploration、Metadata、Monument及MonumentReceivers，新字段接入既有导出及Nebula快照；业务状态仍由各自领域持有。
- 当前格式只恢复当前业务状态，不校准历史3.0研究进度，不注册退休科技。2.2物理兼容由LegacySave承担，文明业务使用当前初始状态且不能授予通关资格。
- 切档清理几何、分钟、任务、UI快照缓存；缓存不是持久化真源。
- 主机拥有研究、认领、任务交付和奖励结算，客户端只发目标身份。主机从连接对应的IPlayerData获取位置和星球，不采信FE请求提供的位置声明。
- 完成资格一旦被沙盒或一键解锁禁用，必须随存档保持；缺少资格块的存档不能补授通关记录。旧是否玩过标记不折算次数，正式通关按世界身份去重。
- 跨域调用避免反向锁；ResearchManager.Sync 内不得调用 DataCenterInventory。解析批次在锁内登记原型奖励，释放锁后立即入库；研究完成的探索加速与提示在锁外主线程推进。

## 新增与调整科技（强制）

- 先区分研究资格与树上连线。`PreTechs` 只保留本系列相邻等级等需要直接展示的连接；跨页、跨区域、矩阵阶段与原版物流资格放入 `PreTechsImplicit`，不得画穿过其他科技区或大块空白的长竖线。改为隐式前置不能移除研究门槛。
- 同系列升级从1级开始连续编号，一行向右排列，同级列对齐。矩阵阶段、科技ID偏移、展示等级分别建模；同一矩阵支持多级时，等级仍递增，不能出现1、1、2或首格从2级开始。
- 有限节点的 `Level` 与 `MaxLevel` 必须等于该节点等级；无限节点的起始等级承接前一有限等级。原型等级在初始化研究状态之前确定，不能在布局刷新时改写。已使用的稳定ID不得为重新排版而重编号。
- `UITechNode` 等级文字读取 `TechState.curLevel`。排查重复或错位等级须同时核对原型、已加载构建和存档状态，不能只改名称、坐标或标签掩盖；不得擅自重置、补偿或迁移历史研究进度。
- 使用统一页基准、网格间距和系列行列定义。修改科技位置时同时核对原版、创世、星环与深空来敌的相邻区域；不能以把新节点移到远处空地作为避让完成。
- 连线只连接同页、当前实际显示的节点；隐藏、问号预告与页面切换必须同步处理箭头、输出横线和公共竖线，不能只隐藏端点或在补丁中重新显示跨页箭头。
- 成本重算或外部模组改表后，隐式资格不能被矩阵材料前置覆盖。前置关系修改后刷新 `preTechArray`、`postTechArray`，并让预告判断与正式研究判断使用一致的资格。
- 同系列等级共用白色透明科技图标；名称、效果说明、研究材料及元数据买断数量必须与最终原型一致。玩法合同和参数分别写入 `GAME_DESIGN.md` / `GAME_DESIGN_SPEC.md`，本节只约束实现与检查。
- 静态自审必须列出每个节点的ID、等级范围、行列、显式及隐式前置，并检查整条系列。游戏画面需由用户在当前构建实际确认；编译通过不能证明无长线、无重叠或等级显示正确。

## 研究边界

- WorldviewRecipe.AnalysisItemId显式定义唯一实物样本，培育与繁育不能重新依靠所有输入输出猜测。
- 未解析结果只公开已有未完成线索的样本，共享槽从该样本已探索未完成内容中随机选结果，不区分配方/特质优先级。没有待解析线索的样本不得在页面预告。
- 普通样本成功投入与损毁均消费实体，只有成功投入推进研究；其余样本回流并保留增产点。内部预算按成功投入计，不向玩家公开；源点阶段恢复无损毁。丰碑结晶为已知终局材料，确定性按件消费并推进丰碑，不返还同件样本。
- 塔体无候选且献祭未开放时不消耗；千塔资格、献祭开放与特质线索是不同状态。
- Memory先恢复每阶段唯一资料，随后按完整分钟提供下一窗口增益。生产变体不计入献祭，不自动截流。
- Frag在取得研究锁之前转入探索，矩阵在取得研究锁之前转入DataCenter扩容；矩阵供料与永久容量不归研究域，不与普通解析重复消费。

## 探索与任务边界

- 首遗物待母星基地数据就绪后在出生半球安全选点，保持探索距离且避开黑雾基地；没有安全位置时重试，不能降级到另一半球。首个矩阵实际生产才启动高级塔补给主线。
- 静默位置/质量确定性固定，首次接近永久记录；阶段不隐藏静默质量层，广播质量在生成时固定。
- 已回收记录保存实际结果，不能在读档或UI刷新时重抽。静默分母只含已发现点，动态/主线不计入，不统计全星区总百分比。
- 动态不设累计星球额度；终极补缺在认领后立即执行，新点避开认领范围。
- 局部探测与认领使用玩家和悬空点位的三维空间距离，岩石星与气巨共用；认领必须验证星球身份，步行和默认悬浮均可到达。首遗物安全选点单独使用地表弧长约束出生点与基地间距。首遗物感知按真实半径覆盖所在星球低空，其余局部感知与永久发现分开；图形强度不代替实际认领判定。
- 回收提示和档案正文由已结算点位在本端生成本地化文本；主机只广播实际结果身份与参数。关键信号由主线程队列显示确认弹窗，普通点浮现提示；客户端提示不得再次触发奖励，显示和读档不得重抽。
- 终极任务到地从真实背包交付Memory，不取亚空间；主机验证位置与唯一流水，重发只返回既有回执，不重复扣物或推进。
- 物资奖励统一调用DataCenterInventory.AddExplorationReward；UI不能直接发物品。
- 不创建自动移动命令；机甲移动能力通过玩家正常研究取得，只有玩家点击可建立原版位置标注。

## 禁止恢复的路径

不恢复协议购买、远古科技点、成就领奖、黑雾样本门槛或每日奖励系统。剧情终极任务不扩展成独立通用任务货币体系。
