# UI/MainPanel — FE功能面板

页面按玩家任务组织。根层只拥有外壳、路由和注册表，业务状态归Logic领域；玩法和参数以GAME_DESIGN及GAME_DESIGN_SPEC为准。

## 页面与所有者

| 分类 | 页面 | 数据来源 |
| --- | --- | --- |
| 任务 | 文明寻踪、遗迹探索 | ExplorationManager、ResearchManager、AbilityTasks |
| 配方 | 四种生产塔型 | ResearchManager.GetRecipeRecordSnapshots、RecipeManager |
| 管理 | 丰碑建设、亚空间仓储 | MonumentManager、MetadataExtraction、DataCenterInventory |
| 资料 | 使用指南、手记、消息记录 | ResearchManager、DevelopmentDiary、MessageLog |
| 设置 | 单页分组设置 | ModSettings、Miscellaneous |

MainWindowPageRegistry是唯一页面注册表，两种外壳共用。首次默认文明寻踪，后续恢复上次页面；X、Esc、游戏关窗、外壳切换和读档均保留路由，任务完成及通知不覆盖选择。跨页统一使用MainWindow.NavigateToPage。Shift+F打开，Ctrl+Shift+F切换外壳；通信未建立前仅开放资料中的使用指南。旧存档页面键由注册表映射到新目录。

## 视觉与生命周期

- 外壳已给设计区四边10px间距，页面使用1082×767画布，不再增加一层相同间距。
- Theme/CardBrowserPage提供窄单列目录、分页、状态和宽正文；业务页只提供PageCard数据和领域操作。正文从顶部排起，切换条目回到顶部，文字、视口和滑条使用相同上下边界。
- 稳定键只保持选择态，不显示内部ID。卡片可直接点击，不使用循环切换按钮代替选择。
- 可见页面低频读取快照，离屏不刷新；动态长文本使用裁剪与滚动，不固定高度截断。
- 配方按生产塔型分子页，解析记录保持固定位置与发现/解析/完成三态；定向解析能力只为已有线索公开结果并提供选择。未发现内容保持匿名；已解析配方显示实际名称、数量和概率。
- HUD读取ExplorationDetector的分槽投影：主线常驻，已固定独立任务各自显示，普通/精良/珍贵遗迹与广播各共用一槽，固定目标优先，否则显示最近已发现候选；各槽独立固定、取消及续接。UI复用条目池，每条拥有自己的预览、取消抑制和蓝线，整组按全部可见条目的高度避让；复用原版黑雾分组标题置顶，条内显示强度百分比，左侧原版等级文字显示当前主线或终极任务的阶段序号、普通地点的质量等级，匿名首遗物不显示序号；主线等待资格时保留条目与待完成序号，仍可关闭该槽指引；不显示开启/取消文字。首遗物保持匿名且不可精确指引，其他已发现地点悬停临时显示指引、移开隐藏，点击固定或取消；取消后移出条目才恢复预览。选定目标离开感知范围仍保留点击取消操作，隐藏强度条和百分比；天体线与地点线由逻辑域按目标星球切换，布局在UIGame._OnLateUpdate后更新，标题横向跟随原版分组标题，不以位置缓动锁住旧横坐标；右侧原版追踪图标在悬停或固定指引时显示，去除隐藏地点名的宽度占位，挂在条目根节点以避开条框Mask及隐藏控件父节点的影响。连线在主相机onPreCull按最终相机与可见追踪图标中心投影。保留既有字体材质、黑边、避让和原版全屏界面隐藏条件，收集统计归遗迹探索页，不显示内部点位ID。
- 地点列表仅含收到的广播/剧情，静默隐藏点仅在探测或测绘能力已正式发现后展示；档案读取实际奖励记录，不调用随机结算，主线与地点档案不显示回收时间。
- 文明寻踪和遗迹探索各自切换进行中/已完成；页内筛选与选中状态只影响展示，切档清空，不另存任务进度。
- 丰碑建设集中建设、加工与元数据来源快照；元数据自动入库归逻辑域，物品取用与已有实体兑换归亚空间。
- 操作必须调用逻辑命令，客户端通过既有Nebula请求；一次性能力页面只显示条件与实际计数，不发奖励、不创建科研队列。
- 历史手记与当前教程分开，未解锁记录显示问号。
- 不增加协议购买、成就领奖、自动导航或高级塔多缓存操作面板。
