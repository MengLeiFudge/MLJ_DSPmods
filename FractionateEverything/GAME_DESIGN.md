# Fractionate Everything 游戏设计

本文是 FE 当前体验、系统关系、职责边界与设计红线的真源。数值、公式、状态和结算顺序见 `GAME_DESIGN_SPEC.md`。

## 1. 设计目标

万物分馏是一条逐步被重新发现的生命工业路线。玩家从简单的矿物复制与样本解析起步，经由遗迹、矩阵和生产扩张，建立能够供养、繁育和重构物质的工业体系。

前期给出短而可执行的目标，中期让探索、研究与生产互相推动，后期让规模化产线支撑持续研究和终极任务。机制随着需要展开；尚未解析的结果保留未知感。既有生产、库存和原版科技能够表达的状态，不再建立第二套成长真源。

## 2. 世界观与开局

古文明留下了拥有生命特征的工业技术。COSMO不能直接提供它的知识；伊卡洛斯从遗迹中的物质样本、零散记录和仍在运作的接口重新认识这条道路。

首遗物出现在母星出生点所在半球，与出生点保持一段探索距离，并避开实际黑雾基地。它提供基础塔、基础塔制造配方、普通矿物样本线索及原胚培育线索；首次回收还完整授予机械骨骼步行升级链，让后续跑图更轻快，兼容模组附带的科技效果。普通矿物复制仍需概率解析。开局不提供原胚或高级塔，使最初的操作只涉及电力、传送带和样本。

首次实际生产电磁矩阵后，阶段主线才提供原胚与高级交互塔，并引导供养和培育。前期原胚与交互塔可以继续从探索补给取得，反向繁育是中后期研究目标，不是启动生命工业的必要前置。

主线从母星扩展到出生星系，再扩展到具备实际曲速能力后可达的邻近星系。节点给出简短文明记录与可行动提示，不要求稀有星体或黑雾战斗。遗迹回收以可确认的弹窗呈现实际结果，并留存档案。

已完整体验生命工业的本地档案可以在新存档中采用更早开放堆叠的路线。路线写入当前存档，联机以主机为准。只有正常游玩且具有完整资格记录的存档可以授予本地完成标记；沙盒、一键解锁与旧格式不能授予，禁用资格随当前存档永久保存。

## 3. 五塔工业

工业体系由两座基础塔和三座高级生命塔组成。

| 塔型 | 职责 |
| --- | --- |
| 基础矿物塔 | 自动匹配已解析普通矿物配方，复制同种资源 |
| 基础解析塔 | 成功消耗指定样本推进研究，失败回流，按资格处理残片和献祭 |
| 高级矿物塔 | 使用普通矿物与珍奇催化剂增殖珍奇资源 |
| 高级交互塔 | 培育高级塔，以塔体模板繁育原胚 |
| 高级转化塔 | 置换指定燃料或机器，回收部分被替换部件 |

基础塔独立制造、接入电网、无需选择配方。它们的正面接口还可上传到亚空间。高级塔从已解析配方中选择工作内容，接收全部反应物和矩阵供养；混带比例、失败回流、产物竞争出口及旧物排空构成实际工程选择。

高级塔的工作和待机都消耗营养。营养不足会逐渐损失耐久，充足供养能够恢复；无人机不能维修生命塔。主动拆除返还缓存，损毁不返还。源点（Memory）改变效率，不替代矩阵供养，也不因源点断供额外损毁塔体。

全部分馏采用概率反应与批量期望取整。主消耗物在失败轮回流，催化剂按成功轮概率消耗。正常生产时使用全局集装输出；主消耗物不足一轮后释放尾料，不能因为残留催化剂永久等待满堆。

普通矿物只用自身。珍奇基础配方使用普通资源和对应催化剂；单极磁石基础版不消耗源点，另有消耗源点的简化变体。两者并存，让玩家选择资源组合或持续记忆消耗。

## 4. 研究与发现

配方显式指定唯一解析样本：培育使用原胚，反向繁育使用对应塔体。探索只公开样本，不在完成前展示结果名称、产物或用途。样本页面只保留已经取得且尚未完成的线索，不预告未来内容。每种样本共用一个进度槽，满槽从该样本已探索未完成内容中随机取得一项，配方与特质没有额外优先级。

普通样本解析有成功、损毁和流回三类结果。样本价值越高，成功率连续下降、损毁率连续上升；成功投入推进研究，损毁额外消耗样本，流回保留增产点。内部成功投入量随内容所属阶段成长，已经发现的内容不因玩家进入下一阶段自动涨价；塔体和源点独立计算。源点恢复按概率成功且不损毁，失败可继续循环。玩家只看到进度与概率，不公开内部预算和所需样本总数。

同种高级塔首次达到亚空间库存门槛后，对应特质才能进入探索候选；首次千塔还产生献祭主线，回收后正式开放献祭。有待解析内容时先解析，无候选时才献祭产出源点。库存上传本身不触发献祭。

源点先承担阶段资料恢复：每个矩阵阶段只恢复一次资格，再由矩阵逐项研究成长科技。物流科技使用原版科技资格与遗迹接口恢复，不重复收取源点。

阶段恢复之外，源点还可用于持续献祭或独立生产变体。解析塔按完整分钟统计实际献祭投入，用于下一分钟全部高级塔的相对成功率增益；每分钟替换，不永久累积。玩家可以自主分流生产变体所需源点，系统不从这些产线强行抽走物品。

## 5. 探索

探索区分静默遗迹、普通动态广播、阶段主线和重要任务。静默点的位置与质量在生成时固定，成长只开放更深层的既有地点；已回收点不刷新。动态点根据生成时的矩阵阶段决定质量，之后不自动升档，累计生成不设玩法总上限。

静默点主要提供普通矿物和生产补给，研究线索受待解析数量限制，源点只出现在少数深层地点。主线保证关键启动物资与早期研究来源，动态点和后期献祭提供持续补充。

原胚与高级交互塔的探索补给在首次电磁矩阵生产后开放。每次回收分别检查对应物品的亚空间库存，低库存时才有机会获得；背包与已放置建筑不参与判定。补给资格变化不改变地点质量。

探测使用当前位置附近的地表距离，HUD只显示可探范围中的最高强度；进入可回收距离显示满强度。岩石星球必须实际落地才能回收，不能在高空只靠投影触发。没有方向箭头、点位内部ID或全星区收集百分比。地点列表只包含已经收到的广播和剧情目标，不能提前暴露静默点；收集统计限当前星球、当前星系的已开放静默遗迹。

回收只结算一次，并保存实际奖励及文明记录身份；提示和档案按查看者当前语言呈现。气态巨星只设少量可飞抵的悬空点，认领范围不随星球半径放大。成长后的主动位置标注复用原版标记，不创建移动命令。

## 6. 亚空间与物流

亚空间是唯一的跨星球共享库存。每种物品独立计容量，不竞争一个共享总格数；低价值原料按对数价值获得更大的基础额度，建筑和未知估值物品保留可用底线。向基础解析塔持续投入矩阵，可永久提高全体物品的容量；矩阵等级越高扩容越快，已有容量越大扩容越慢。停供不缩水，多塔与集装只改善供料稳定性，不突破全局扩容速度。矩阵进入扩容供料后不再同时参与研究或供养。终极仓储解除玩法容量限制，数量与增产点仍受数值安全边界约束。

手动存取和基础塔正面上传不额外消耗能量。普通上传必须先确认可完整接收，满仓不能吞物；探索奖励可突破普通容量，仍可正常提取。

物流交互站负责站内库存与亚空间的自动交换，保留每槽传输模式、阈值、增产点、蓝图和复制粘贴。能耗按物品价值及实际搬运量结算，能效科技降低成本。站点窗口负责站点状态，主面板不再复制一套物流页面。

## 7. 成长科技

第一页物流科技遵循“原版资格→地点恢复→矩阵研究”；第二页成长科技遵循“矩阵阶段→源点资料恢复→矩阵研究”。特质还要求已经解析对应塔体记录。等级完成状态始终归原版科技系统。节点按矩阵阶段对齐；宇宙矩阵的重复升级合并为同一多级节点，每级提供相同增量，终极科技独占下一列。解锁区域显示本级增量。矩阵总成本和科研工作量分别定义，研究耗时参考原版同矩阵阶段的成长科技；未完成发现资格的节点不能加入研究队列。
科技节点只在自身发现资格完成或已经解锁后显现，连线只连接可见的后续节点。沙盒使用相同显隐规则，但保留无矩阵消耗直接解锁已显现科技及一键解锁全部分馏科技的能力。

保留普通与已玩过两条堆叠路线。普通路线在实际解锁自动集装机或集装分拣器后起步，资格跟随当前模组的制造解锁关系；已玩过路线从早期矩阵阶段起步，两者最终堆叠能力一致。全局堆叠同时影响相关缓存、输出与原版配方时间。

探索常规成长完成或仓储达到累计容量里程碑后，出现对应长链任务：探索恢复跨星球中继、重建星图并连接核心；仓储恢复锚点、重建索引并连接库房。源点通过明确操作分批交付，只扣剩余需求。最终能力直接授予，不消耗矩阵，不进入研究队列。

终极探索持续补足普通动态广播，回收立即补缺；主线与静默点独立。终极仓储提供不受玩法容量限制的共享库存。任务范围控制在少量可达星系，不以全星区跑图拖长流程。

## 8. 操作与反馈

两种面板外壳共用六类十七页，默认打开当前目标。页面围绕可做的事组织，使用窄单列目录与宽详情正文，图标与状态辅助选择；正文从顶部排起，长文本在统一裁剪范围内滚动，滑条与视口边界一致。

| 分类 | 页面 |
| --- | --- |
| 指引 | 当前目标、主线记录、使用指南 |
| 研究 | 解析样本、阶段恢复、塔体特质 |
| 探索 | 信号追踪、地点档案、终极任务 |
| 工业 | 配方图鉴、生命塔、亚空间仓储 |
| 手记 | 1.x手记、2.x手记、伊卡洛斯手记 |
| 设置 | 亚空间存取、界面与兼容 |

G手册以伊卡洛斯的发现为视角，只在关键节点给出简短叙事，从“神秘信号？”开始。详细操作放在随实际发现开放的面板指南中。历史开发手记与当前教程分开，伊卡洛斯记录对应生命工业。未解锁手记显示问号。完整配方信息设置不能突破未知结果边界。中文玩家文案统一使用“源点”“残片”，不展示内部候选、阶段编号或迁移过程。

塔窗口区分解析和献祭、缺少矩阵和缺料、堵塞和集装；生命塔页按类型汇总状态，不逐帧扫描全部星球。回收结果进入弹窗与档案，解析发现使用短暂提示。记录页面不显示不必要的回收时间。信号HUD沿用原版鼠标提示的黑边白字，随黑雾列表与教学面板的可见内容动态避让；左侧下方空间不足时移到这些面板右侧。随原版界面隐藏条件在科技树等全屏界面隐藏。
解析塔使用原版科研瓶图标表达研究成果和概率，不生成实体研究产物。基础塔没有输入时，窗口保持原版高度。

## 9. 存档、迁移与联机

当前格式保存研究样本关系、共享进度、阶段投入、分钟献祭、库存、成长路线、任务步骤、交付数量、回收记录及高级塔缓存。静默位置可以由种子重建，已经结算的奖励不能重新抽取。切档必须清理缓存与快照。

当前玩法面向新存档，不转换旧版本研究、等级、探索与物理引用。持久身份使用稳定内容、配方和原型ID，不使用类名。

Nebula由主机结算研究、探索、交付、库存和高级塔。客户端动作只指定目标，主机读取连接玩家位置、星球与移动快照，验证实际落地、距离与剩余需求；重发不能重复扣款或发奖。回收提示独立传输已经结算的结果身份与参数，各端使用自己的语言生成标题和正文。中途加入同步当前业务状态。

高级塔选定配方通过稳定整数身份进入蓝图与复制粘贴，配方必须存在、已解析且与塔型匹配；缓存与营养不属于蓝图配置。

## 10. 兼容与边界

第三方兼容可以调整科技位置、物品语义和教程布局，不建立第二套研究、库存或塔体状态。基础矿物仍以普通自然资源为边界，工业制品不会因取得或探索而变为可复制矿物。

高级转化只覆盖明确有用途的燃料和机器关系。内部旧名称可以保留为实现别名，不注册旧塔、旧协议或旧成长系统。

## 11. 设计红线

- 不恢复协议购买、远古科技点、商店、抽奖、VIP或每日领奖循环。
- 不以黑雾、稀有星体或全星区收集阻塞主线与终极能力。
- 不把概率解析替换成确定样本兑换，不提前泄露未知结果。
- 不让源点替代矩阵供养，不自动截流生产变体的投入。
- 不让静默点随阶段重复刷新，不重新抽取已回收奖励。
- 不自动导航或创建移动命令；探索改善移动能力通过原版科技奖励结算，位置标注只响应玩家明确操作。
- 不允许客户端自行结算奖励、任务交付或生产。
- 不将面板或兼容层变成业务状态真源。
