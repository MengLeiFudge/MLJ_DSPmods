# Fractionate Everything 游戏设计

本文是 FE 当前体验、系统关系、职责边界与设计红线的真源。数值、公式、状态和结算顺序见 `GAME_DESIGN_SPEC.md`。

## 1. 设计目标

万物分馏是一条逐步被重新发现的生命工业路线。玩家从简单的矿物复制与样本解析起步，经由遗迹、矩阵和生产扩张，建立能够供养、繁育和重构物质的工业体系。

前期给出短而可执行的目标，中期让探索、研究与生产互相推动，后期让规模化产线支撑持续研究和终极任务。机制随着需要展开；尚未解析的结果保留未知感。既有生产、库存和原版科技能够表达的状态，不再建立第二套成长真源。

## 2. 世界观与开局

古文明留下了拥有生命特征的工业技术。COSMO不能直接提供它的知识；伊卡洛斯从遗迹中的物质样本、零散记录和仍在运作的接口重新认识这条道路。

首遗物出现在母星出生点所在半球，与出生点保持一段探索距离，并避开实际黑雾基地。它提供基础塔及制造配方；首次回收还完整授予机械骨骼步行升级链，让后续跑图更轻快，兼容模组附带的科技效果。普通配方随矩阵科技研究开放。开局不提供原胚或高级塔，使最初的操作只涉及电力、传送带和矩阵科技。

首次实际生产电磁矩阵后，阶段主线才提供原胚与高级交互塔，并引导供养和培育。前期原胚与交互塔可以继续从探索补给取得，反向繁育是中后期研究目标，不是启动生命工业的必要前置。

主线从母星扩展到出生星系，再扩展到具备实际曲速能力后可达的邻近星系。节点给出简短文明记录与可行动提示，不要求稀有星体或黑雾战斗。遗迹回收以可确认的弹窗呈现实际结果，并留存档案。

已完整体验生命工业的本地档案可以在新存档中采用更早开放堆叠的路线。路线写入当前存档，联机以主机为准。只有正常游玩且具有完整资格记录的存档可以授予本地完成标记；沙盒、一键解锁与旧格式不能授予，禁用资格随当前存档永久保存。

## 3. 五塔工业

工业体系由两座基础塔和三座高级生命塔组成。

| 塔型 | 职责 |
| --- | --- |
| 基础矿物塔 | 自动匹配已解析普通矿物配方，复制同种资源 |
| 基础解析塔 | 成功返还指定样本并推进研究，损毁消失，未处理部分回流，按资格处理残片和献祭 |
| 高级矿物塔 | 以资源原料或源点和对应催化剂增殖珍奇资源 |
| 高级交互塔 | 培育高级塔，以塔体模板繁育原胚 |
| 高级转化塔 | 置换指定燃料或机器，回收部分被替换部件 |

基础塔独立制造、接入电网、无需选择配方。它们的正面接口还可上传到亚空间。高级塔从已解析配方中选择工作内容，接收全部反应物和矩阵供养；正面只输出配方产物，两个侧面按玩家连接方向输入或输出流动物。备用食物槽独立保留少量未食用矩阵，消化槽只容纳正在消化的一件。主料、催化剂、流动物和产物按物品独立限量，每种产物缓存至少容纳一个成功轮的完整产量。催化剂与食物保留小容量储备，不能占用其他主料的空间。超出对应槽位容量的投入保留增产点流出；旧缓存逐步排空，玩家可直接取出或补入反应物。混带配比、失败回流和产物积压构成实际工程选择。

高级塔逐件消化矩阵，以当前消化物决定速度；工作按实际消耗的主料计能，待机也持续消耗。食物增产点只延长供养时间，不额外提速。在消化且仍有备用食物时恢复耐久，仅剩正在消化的一件时维持耐久，两者皆空时逐渐损坏；无人机不能维修生命塔。备用食物可直接取出，正在消化的物品只能长按销毁。主动拆除返还未食用食物和其他缓存，不返还已消化物，损毁不返还。源点（Memory）改变效率，不替代矩阵供养，也不因源点断供额外损毁塔体。

全部分馏采用概率反应与批量期望取整。主消耗物在失败轮回流，催化剂按成功轮概率消耗。正常生产时使用全局集装输出；主消耗物不足一轮后释放尾料，不能因为残留催化剂永久等待满堆。

分馏必须体现为“少数被处理、多数流过”。进入塔且会参与该塔反应的物品，每件只以较低概率被处理，可另有较低的损毁概率；既未处理也未损毁的部分保留增产点，从另一侧面流出，可经回环再次进入。任何反应都不得把进入的反应物整批确定性消耗。常规反应保持较低处理率，长期运行的纯消耗入口可以适当提高；上限指无增幅的基础概率，已定义的增益按各自规则叠加。具体上限与参数见规格。每种塔的全部功能中，至少有一个配方在正面输出实物产物。高级塔把矩阵作为食物接收时不属于反应，只按食物槽填充规则收料。

普通矿物只用自身。珍奇催化按天然丰度区分投入复杂度：可燃冰、金伯利矿石和光栅石使用单一普通资源；分形硅石、有机晶体和刺笋结晶使用复合普通资源；单极磁石使用分形硅石、有机晶体和刺笋结晶的组合。全部珍奇矿物另有消耗源点的重构变体，让玩家选择资源组合或持续记忆消耗，两类路径均需要对应珍奇催化剂。

## 4. 研究与发现

配方按取得方式分级：普通配方随对应矩阵科技研究开放；稀有配方使用明确指定的实物样本进行概率解析；传说配方由高级遗迹残页或持续献祭恢复。基础矿物复制与高级塔培育属于普通，珍奇催化与物质置换属于稀有，反向繁育与源点重构属于传说。已解锁的配方永久保留。
稀有配方显式指定唯一解析样本。探索可以取得样本线索，当前阶段的稀有样本也可直接投入解析塔，以首次成功建立线索并推进研究。红矩阵阶段起还可持续投入电路板低效制取置换研究样本，使早期自动化不依赖先制造稀有产物。电路板成功时从正面输出候选样本并记录线索，损毁消失，其余原样流出；相关配方全部恢复后停止处理。发现只公开样本，不在完成前展示结果名称、产物或用途。样本页面只保留已经取得且尚未完成的线索；每种样本共用一个进度槽，满槽从该样本已有线索的未完成内容中随机取得一项。

普通样本解析有成功、损毁和流回三类结果。样本价值越高，成功率连续下降、损毁率连续上升；成功推进研究，同时把同件样本从正面返还，玩家须安排正面样本回流才能持续研究；损毁消耗样本，未处理的侧面流回保留增产点。没有可研究内容时不判定损毁。内部成功次数预算随内容所属阶段成长，已经发现的内容不因玩家进入下一阶段自动涨价；塔体和源点独立计算。源点恢复按概率成功且不损毁，成功源点消耗，失败可继续循环。玩家只看到进度与概率，不公开内部预算和所需样本总数。

同种高级塔首次达到亚空间库存门槛后，对应特质才能进入探索候选；首次千塔还产生献祭主线，回收后正式开放献祭。有待解析内容时先解析，无候选时才献祭产出源点。库存上传本身不触发献祭。

源点先承担阶段资料恢复：每个矩阵阶段只恢复一次资格，再由矩阵逐项研究成长科技。物流科技使用原版科技资格与遗迹接口恢复，不重复收取源点。

阶段恢复之外，源点还可用于持续献祭或独立生产变体。解析塔按完整分钟统计实际献祭投入，用于下一分钟全部高级塔的相对成功率增益；每分钟替换，不永久累积。玩家可以自主分流生产变体所需源点，系统不从这些产线强行抽走物品。

## 5. 探索

探索区分静默遗迹、普通动态广播、阶段主线和重要任务。静默点的位置与质量在生成时固定，成长只开放更深层的既有地点；已回收点不刷新。低级点数量较少、单点补给较多，让无黑雾存档也能启动生产。动态点根据生成时的矩阵阶段决定质量，之后不自动升档；每颗星球有同时存在的普通广播上限和生成冷却，残片不能绕过限制。

静默点主要提供普通矿物和生产补给，研究线索受待解析数量限制，源点只出现在少数深层地点。主线保证关键启动物资与早期研究来源，动态点和后期献祭提供持续补充。

原胚与高级交互塔的探索补给在首次电磁矩阵生产后开放。每次回收分别检查对应物品的亚空间库存，低库存时才有机会获得；背包与已放置建筑不参与判定。补给资格变化不改变地点质量。

探测使用当前位置附近的空间距离，HUD分别显示普通、主线及高级地点的最高强度，避免普通点掩盖目标；进入可回收距离显示满强度。岩石星球允许步行或低空悬浮回收。没有方向箭头、点位内部ID或全星区收集百分比。地点列表只包含已经收到的广播和剧情目标，不能提前暴露静默点；收集统计限当前星球、当前星系的已开放静默遗迹。

回收只结算一次，并保存实际奖励及文明记录身份；提示和档案按查看者当前语言呈现。气态巨星只设少量可飞抵的悬空点，认领范围不随星球半径放大。成长后的主动位置标注复用原版标记，不创建移动命令。

## 6. 亚空间与物流

亚空间是唯一的跨星球共享库存。每种物品独立计容量，不竞争一个共享总格数；低价值原料按对数价值获得更大的基础额度，建筑和未知估值物品保留可用底线。向基础解析塔持续投入矩阵，以较低概率进入全局扩容供料，可永久提高全体物品的容量；矩阵等级越高扩容越快，已有容量越大扩容越慢。停供不缩水，多塔与集装只改善供料稳定性，不突破全局扩容速度。扩容缓存已满后的矩阵沿同一低概率处理入口献祭成源点，高档矩阵的源点产率更高；未被处理的矩阵保留增产点流回，已进入扩容供料的矩阵不再参与其他结算。终极仓储解除玩法容量限制，数量与增产点仍受数值安全边界约束。

手动存取和基础塔正面上传不额外消耗能量。普通上传必须先确认可完整接收，满仓不能吞物；探索奖励可突破普通容量，仍可正常提取。

物流交互站负责站内库存与亚空间的自动交换，保留每槽传输模式、阈值、增产点、蓝图和复制粘贴。能耗按物品价值及实际搬运量结算，能效科技降低成本。站点窗口负责站点状态，主面板不再复制一套物流页面。

## 7. 成长科技

第一页物流科技遵循“原版资格→地点恢复→矩阵研究”；第二页成长科技遵循“矩阵阶段→源点资料恢复→矩阵研究”。特质还要求已经解析对应塔体记录。等级完成状态始终归原版科技系统。节点按矩阵阶段对齐；宇宙矩阵的重复升级合并为同一多级节点，每级提供相同增量，终极科技独占下一列。解锁区域显示本级增量。矩阵总成本和科研工作量分别定义，研究耗时参考原版同矩阵阶段的成长科技；未完成发现资格的节点不能加入研究队列。

科技节点只在自身发现资格完成或已经解锁后显现，连线只连接可见的后续节点。沙盒使用相同显隐规则，但保留无矩阵消耗直接解锁已显现科技及一键解锁全部分馏科技的能力。

保留普通与已玩过两条堆叠路线。普通路线在任一集装设备的主配方或显式前置科技完成后起步，替代配方提前开放制造资格不代表完成集装研究。双向分拣保留为玩家自行研究的独立能力。已玩过路线从早期矩阵阶段起步，两者最终堆叠能力一致。全局堆叠同时影响相关缓存、输出与原版配方时间。

探索常规成长完成或仓储达到累计容量里程碑后，出现对应长链任务：探索恢复跨星球中继、重建星图并连接核心；仓储恢复锚点、重建索引并连接库房。源点通过明确操作分批交付，只扣剩余需求。最终能力直接授予，不消耗矩阵，不进入研究队列。

终极探索以维持普通动态广播为目标，仍遵守星球上限和冷却，在可生成时补缺；主线与静默点独立。终极仓储提供不受玩法容量限制的共享库存。任务范围控制在少量可达星系，不以全星区跑图拖长流程。

## 8. 操作与反馈

两种面板外壳共用六类页面，默认打开当前目标。通信建立前只开放百科目录；通信恢复后开放其余页面，各业务继续按实际资格执行。页面围绕可做的事组织，使用窄单列目录与宽详情正文，图标与状态辅助选择；正文从顶部排起，长文本在统一裁剪范围内滚动，滑条与视口边界一致。

| 分类 | 页面 |
| --- | --- |
| 指引 | 当前目标、主线记录、百科、消息日志 |
| 研究 | 解析样本、阶段恢复、塔体特质 |
| 探索 | 信号追踪、地点档案、终极任务 |
| 工业 | 配方图鉴、生命塔、亚空间仓储 |
| 手记 | 1.x手记、2.x手记、伊卡洛斯手记 |
| 设置 | 亚空间存取、界面与兼容 |

G手册以伊卡洛斯的发现为视角，只在关键节点给出简短叙事，从“神秘信号？”开始。百科目录始终存在，未恢复条目以乱码呈现，随阶段推进或少量高级探索残页解开；满仓提示直接说明为解析塔供电、从侧面投入矩阵扩容的下一步。历史开发手记与当前教程分开，伊卡洛斯记录对应生命工业。未解锁手记显示问号。配方完成恢复后直接展示完整信息，完成前不展示未知结果。中文玩家文案统一使用“源点”“残片”。
短暂的鼠标提示照常显示，并进入当前游戏的内存消息日志；日志仅保留最近的有限条目，切档清空。遗迹确认弹窗同样留存日志，方便错过提示时回看。

塔窗口区分解析和献祭、缺少矩阵和缺料、堵塞和集装；生命塔页按类型汇总状态，不逐帧扫描全部星球。回收结果进入弹窗与档案，解析发现使用短暂提示。记录页面不显示不必要的回收时间。信号HUD沿用原版鼠标提示的黑边白字，随黑雾列表与教学面板的可见内容动态避让；左侧下方空间不足时移到这些面板右侧。随原版界面隐藏条件在科技树等全屏界面隐藏。

解析塔使用原版科研瓶图标表达研究成果和概率；成功研究的同件样本、电路板制取的样本及献祭源点从正面产物口输出，实物缓存可取。样本返还与对应研究进度是同一次成功，不重复计算成功率。正面实物产物满载时，解析塔停止研究和收料，待输出空间恢复后继续。基础塔没有输入时，窗口保持原版高度。

高级塔以配方槽打开原版配方选择器，只列本塔类型已经解锁的配方；分馏页第一行集中展示塔，后续配方按塔型分行。窗口沿用原版槽位风格，最左侧集中显示配方速率、成功率与食物速度，左上展示流动输入，右上展示流动输出，下方展示配方产物，各区域留出内边距。每个槽位显示独立容量、每轮比例、处理或消耗概率，以及当前处理速率或预计产出，帮助玩家判断缺料、配比和回流。备用食物与消化槽独立置于最右侧，消化进度以图标与无数值进度条呈现；反应物可取出或补入，取出备用食物和销毁消化物具有不同的点击语义。

## 9. 存档、迁移与联机

当前格式保存研究样本关系、共享进度、阶段投入、分钟献祭、库存、成长路线、任务步骤、交付数量、回收记录及高级塔缓存。静默位置可以由种子重建，已经结算的奖励不能重新抽取。切档必须清理缓存与快照。

当前玩法面向新存档，不转换旧版本研究、等级、探索与物理引用。持久身份使用稳定内容、配方和原型ID，不使用类名。

Nebula由主机结算研究、探索、交付、库存和高级塔。客户端动作只指定目标，主机读取连接玩家位置、星球与移动快照，验证实际落地、距离与剩余需求；重发不能重复扣款或发奖。回收提示独立传输已经结算的结果身份与参数，各端使用自己的语言生成标题和正文。中途加入同步当前业务状态。

高级塔选定配方通过稳定整数身份进入蓝图与复制粘贴，配方必须存在、已解析且与塔型匹配；缓存与消化状态不属于蓝图配置。

## 10. 兼容与边界

第三方兼容可以调整科技位置、物品语义和教程布局，不建立第二套研究、库存或塔体状态。基础矿物仍以普通自然资源为边界，工业制品不会因取得或探索而变为可复制矿物。

高级转化只覆盖明确有用途的燃料和机器关系。内部旧名称可以保留为实现别名，不注册旧塔、旧协议或旧成长系统。

- 不恢复协议购买、远古科技点、商店、抽奖、VIP或每日领奖循环。

- 不将面板或兼容层变成业务状态真源。
