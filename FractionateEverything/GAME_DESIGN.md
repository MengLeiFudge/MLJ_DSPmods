# Fractionate Everything 游戏设计

本文是 FE 当前体验、系统关系、职责边界与设计红线的真源。可执行数值、公式、时序、持久化和联机规则见 `GAME_DESIGN_SPEC.md`。

## 1. 设计目标

“万物分馏”是一套被重新发现的生命型工业，而不是原版制造配方的随机翻版。

玩家的核心体验是：

- 在宇宙中寻找古文明留下的禁忌技术，并逐步理解它的用途。
- 通过解析未知方向发现配方，而不是在开局看到完整目录。
- 为多输入、多输出、矩阵供养和生命塔耐久建立可持续自动化。
- 用更复杂的产线换取原版路线无法提供的资源增殖、原胚繁育与部件回收。
- 随着全局成长，重构既有产线以取得更高吞吐和更小占地。

设计优先做减法。研究、探索、生产和科技已经能够表达的进度，不再包装成独立任务、成就、领奖或额外货币系统。高级内容必须提供明确生产价值和工程选择，不能只靠倍率或内容数量证明存在价值。

## 2. 世界观与开局

古文明曾研究具有维生、繁育和重构能力的生命型工业，其失控与黑雾异常有关。COSMO 主脑无法直接提供这条被禁止的技术路径；玩家只能通过遗物、解析和自身工业重新建立它。

玩家首次生产电磁矩阵后，出生星上会生成一个永久首遗物信号。它是唯一由 FE 自动建立导航的探索点，用于确保玩家已经能够供养生命塔，并且无需先获得高级探测能力即可开始模组主线。抵达后，首遗物直接建立分馏亚空间通信和主面板访问，发放两种基础塔、通用原胚及两张基础复制配方；不再经过一个可见或隐藏的“亚空间网络”科技节点。

首遗物只提供启动条件，不保证直接取得全部高级塔。玩家仍需解析方向、发现培育配方，并通过后续探索或黑雾战斗持续补充通用原胚。第一次发现某类高级塔的配方时，古文明档案会恢复一座该类原型，供玩家启动相应产线；其后的常规量产依赖原胚培育。

对已经完整体验生命工业的本地档案，新存档采用更快进入高堆叠物流的成长路线，并给予与该路线匹配的物流启动补给。旧版存档不会伪装成已经完成当前成长线。

## 3. 五塔工业

当前工业体系固定采用两座基础塔和三座高级生命塔。

| 塔型 | 定位 | 取得与成本 |
| --- | --- | --- |
| 基础矿物塔 | 自动识别普通自然资源并进行同物增殖 | 制造台制作；接入电网 |
| 基础解析塔 | 消耗已经探索到具体内容的物品，推进该物品的共享解析槽 | 制造台制作；接入电网 |
| 高级矿物塔 | 用珍奇矿物催化普通资源，增殖对应珍奇资源 | 原型发现后由原胚培育；矩阵供养 |
| 高级交互塔 | 培育高级塔，并用高级塔模板繁育通用原胚 | 原型发现后由原胚培育；矩阵供养 |
| 高级转化塔 | 对燃料或机器进行置换重构，并回收被替换部件 | 原型发现后由原胚培育；矩阵供养 |

基础塔保持单输入、自动识别、不选择配方的低操作门槛。它们的正面接口还可连接分馏亚空间，作为低吞吐、无额外传输能耗的上传入口。

高级塔先选择已发现配方，再从任意输入端接收反应物和矩阵。它们支持多输入、多输出，并故意要求玩家处理混带比例、旧物排空、失败物回流和多个产物竞争出口等工程问题。无关物品不会被吞掉；换配方时，旧输入和旧产物优先排出。

矩阵是高级塔的食物，不是配方原料或科研货币。更高层矩阵提供更多营养和更高处理速度。高级塔不接入电网：工作和待机都会消耗营养；断粮后仍会按当前耐久比例低速加工，同时持续损失耐久，直至损毁。营养充足时可以缓慢恢复耐久。建造无人机不能维修生命塔，主动拆除会返还缓存，战斗损毁则不会。

分馏结算使用批量期望取整，保证长期统计符合设定概率，同时避免为高流量逐件随机。实际可执行轮数随输入货物堆叠增加；失败轮的普通反应物进入流动输出，低概率消耗物继续留在塔内，直到实际发生消耗。正常运行时，流动输出和产物都等待凑满当前全局堆叠；切换配方后的无关物优先排空，输入全部用完后释放不足整堆的尾料。多个产物按真实库存权重公平争取输出机会。

## 4. 研究与发现

成长统一经过三个阶段：玩家在实地探索中发现一项具体配方、塔特质或科技方向；把探索点指定的承载物品送入基础解析塔；解析完成后，配方或特质立即可用，科技方向则让整条科技行同时显现，再使用原版矩阵逐级研究。探索和解析都不会免费赠送科技等级。

每种承载物品只有一个共享解析进度槽。槽满时，只在该物品已经探索、尚未解析的具体内容中随机选择；只有一个候选时结果确定。同一内容可以在目录中关联多个物品，但一次探索会确定唯一承载物品；内容一旦解析完成，便从全部目录关系中移除，不会重复发现。

研究页显示已经探索的具体内容、对应物品的真实进度和已经解析的成果，不提前泄露未认领信号或尚未探索的目录。配方产物不再自动开放整个关联内容池；后续内容仍须逐项探索。

三类高级塔特质遵循同一流程。同种高级塔在亚空间库存首次达到门槛，只会让对应特质进入探索候选；玩家仍须找到具体信号，再把该塔送入基础解析塔推进共享槽。已有待解析特质时，塔体只用于解析；没有已探索的剩余内容时，本次处理改为献祭，成功后从正面产出 Memory。最近一分钟内的实际献祭规模只增强同种高级塔，玩家因此需要在继续研究、保留库存和换取生产增益之间取舍。高级塔上传到亚空间时按原物品保存，不会自动献祭。解析和献祭互斥，一座塔不会同时获得两种回报。

Memory 是多条科技方向的承载物。探索到哪条科技方向，就把哪条加入 Memory 的共享解析槽；完成解析后才在科技树中显示对应整行。Frag 是特殊解析物，不推进内容槽，而是尝试生成额外探索信号。黑雾提供 Frag 和通用原胚的可选补充来源，但无黑雾存档仍可通过定时信号与资源藏点完整推进主线。

## 5. 探索

除首遗物外，遗物与资源藏点统一表现为“古文明信号”。信号永久存在，允许同时积累多个，直到玩家抵达并回收。

探索信息刻意保持不完整：面板只公开目标星球，以及玩家接近目标星球后的现场信号强度，不公开精确坐标、内容类型或方向箭头。探索点以球形范围认领；固态星球的点位贴近地表，气态巨星的点位位于外层空间。FE 只为首遗物设置一次导航；如果玩家之后手动改选导航，FE 不会覆盖或清除玩家选择。

可生成范围随玩家实际航行能力扩大：先是出生星，再是出生星系，最后是其他星系。更远的信号提供更高价值，但每颗星球拥有有限点位额度，避免无限刷新同一地点。可达范围没有剩余额度时，定时生成暂停，而不是吞掉一个完整周期。

点位内容在抵达时直接结算：研究点记录一项具体内容及其承载物品，资源写入亚空间，并用短暂悬浮文字反馈结果。未抵达前，普通信号仍不公开内容类型。资源点从目标星球实际拥有的矿脉和流体中选择，并根据火山、沙漠、海洋、冰原或气态巨星的环境形成不同偏向；通用原胚始终保留固定出现机会。探索奖励可以突破亚空间常规容量，避免远程发现因库存已满而丢失。

每次发现研究内容只提前当前下一次定时信号，不永久修改基础周期。探索信号成长科技独立缩短定时周期并提高 Frag 掉落；两种加速共同保留最低等待时间。

## 6. 亚空间与物流

分馏亚空间是唯一一套宇宙通用库存。它不与某颗星球绑定，也不是第二个随身背包。每种物品拥有独立容量，不竞争共享总空间；扩容科技统一提高所有物品的容量。

玩家可以在主面板手动存取已接入网络的物品。手动存取和基础塔正面上传不额外耗能。普通上传达到该物品容量后会拒收，且不会先取走再丢失货物；探索奖励是唯一允许突破常规容量的正式入口。

行星与星际物流交互站负责自动交换站内库存和亚空间库存。它们保留每槽传输模式、容量模式、阈值、增产点及蓝图/复制粘贴行为。传输按物品价值和实际搬运数量消耗站内电量；电量不足时只搬运可支付的部分，亚空间存取能效科技降低该成本。

高级塔和其他普通物品一样按真实数量与增产点进入亚空间。同种高级塔首次积累到规定数量后，对应特质永久具备进入探索候选的条件；后续库存下降不会撤销该条件。献祭只会在基础解析塔确认该高级塔当前没有已经探索、尚待解析的内容时发生。

## 7. 成长科技

两项物流交互站科技属于建筑解锁，保留稳定科技 ID 但显示在原版科技树第一页。全部成长科技位于第二页。每个 FE 科技方向也必须先探索具体方向并完成对应物品解析；解析后整行同时显现，首级通过不绘制跨行连线的隐式条件接入，同一行后续等级正常连接前一级。

成长行使用原版同名 `Level/MaxLevel` 等级链和自动等级文本，并使用原版矩阵研究：

- 超级压缩技术：同步影响分馏塔、分拣器、物流交互站、研究站等既有堆叠入口，并按堆叠反比缩短原版配方耗时。普通存档由原版集装物流提供 4 堆叠，只研究 8/12/16/20 四级；已经完整体验生命工业的档案研究 4/8/12/16/20 五级。该行没有额外的宇宙矩阵第六档。
- 亚空间扩容：前八级按阶段使用累计矩阵；第九级进入只消耗宇宙矩阵的长期成长段，最高一万级，每级继续增加所有物品容量。
- 亚空间存取能效、探索信号增幅和三类高级塔特质：使用完整六阶段升级行。电磁至引力阶段逐层累计矩阵，最终宇宙矩阵阶段只消耗宇宙矩阵；每一级都有实际效果。

已经完成过生命工业成长线的本地档案从早期矩阵阶段开始五档超级压缩技术。路线归属写入当前存档，联机参与者看到相同科技原型与主机决定的同一路线。

当一个当前格式的存档已经取得三类高级塔并达到全局最高堆叠时，本地档案才记录“已经完整玩过万物分馏”。这不是成就奖励系统，只用于以后新存档选择成长起点。

## 8. 操作与反馈

FE 主面板保留两种窗口外壳，但共用同一页面注册和业务状态。当前页面包括文明研究、遗物探索、亚空间仓储、开发日记和杂项设置。

文明研究页同时承担具体探索内容、物品共享解析进度、已解析成果和配方图鉴。遗物探索页只展示搜索所需的信息。亚空间仓储页负责库存查看与手动存取。旧协议恢复、远古科技树、成就、独立分馏配方和原版配方强化页面不再作为入口。

高级塔沿用原版分馏塔窗口，只增加配方选择和当前营养显示。耐久继续使用原版建筑耐久表现，不增加独立耐久条、多缓存详情面板或领奖弹窗。

解析发现、探索回收和关键状态使用短暂悬浮文字反馈。教程以五篇当前指南说明开局、亚空间、基础塔、高级生命塔和物流交互站，并保持与 Genesis Book、Orbital Ring 教程布局的兼容。

## 9. 存档、迁移与联机

FE 当前存档格式保存具体探索内容及其承载物品、共享解析进度、亚空间、高级塔实例、成长路线、配方统计、UI 和物流交互站状态。各部分使用稳定命名块；持久身份使用稳定内容 ID、配方 ID、原型 ID 和枚举数值，不依赖 C# 文件名或类名。

版本 11 的资格池和独立科技节点导入当前格式时，会转换为具体已探索内容与原版等级链状态；已经开始或完成的科技行继续保持可见和相应进度。版本 12 直接保存内容到承载物品的映射。FE 2.x 存档仍只迁移原版持久容器中的物理物品、模型和配方引用，使能够对应的旧塔、建筑和蓝图继续解析。旧协议、成就、科技点、塔等级及其他 2.x 自有进度不映射为当前玩法。过渡存档格式同样不会被解释成当前状态。

Nebula 联机由主机统一结算研究、探索、亚空间库存、高级塔反应与成长状态；客户端只提交受限请求并接收快照或合法增量。探索认领使用主机记录的对应玩家宇宙坐标，不采信客户端自行提交的位置。中途加入玩家会收到当前文明、库存与高级塔状态。

高级塔选定配方和真实缓存随存档与联机同步；选定配方通过稳定整数 ID 进入蓝图与复制粘贴路径。不存在或塔型不匹配的 ID 必须被拒绝或归零。

## 10. 兼容与边界

现有第三方模组兼容以不改变当前核心职责为前提保留。Genesis Book 与 Orbital Ring 可以调整科技位置、物品语义或教程解析，但不能建立第二套研究、亚空间或塔状态来源。Nebula 只承载同步，不拥有业务规则。

原版自然资源分类决定基础矿物塔候选，工业制品不会因为被探索或取得而变成可复制资源。高级转化只覆盖明确用途关系中的少量关键燃料和机器置换，不把所有原版制造关系扩展成通用转换网。

内部 `DataCenter` 名称、旧中文常量、旧物理 ID 和旧亚空间科技 ID 可以作为兼容实现继续存在；玩家可见术语统一为“分馏亚空间”“亚空间仓储”和五座当前塔。兼容别名不得注册旧节点或重新暴露旧玩法。

## 11. 设计红线

以下内容不得重新引入：

- 独立协议检索、完整度购买、远古科技点、主路锁定或副产物弃置。
- 正式成就、任务领奖、每日循环、商店、市场、抽奖或 VIP 成长。
- 定向原胚、随机培养、谱系分化、返祖协议或高级解析塔。
- 以黑雾样本阻塞主线，或让无黑雾存档缺失正式内容。
- 为高级配方增加没有独特价值的同质倍率路线。
- 向普通探索信号泄露精确坐标、内容类型或自动方向导航；探索认领前也不得泄露具体研究内容。
- 以物品资格一次开放整个内容池，或让一个探索结果自动进入所有关联物品的解析槽。
- 允许客户端自行结算联机状态，或用类名充当持久化身份。
- 在高级塔窗口重复制造台式缓存面板、额外状态条和不必要的操作层级。

新增内容必须先证明它服务于探索、解析、生命供养或独特工业重构中的至少一项真实选择，并且不会建立与现有系统重复的成长真源。
