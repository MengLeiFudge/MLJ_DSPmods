# Fractionate Everything 3.0 游戏设计

本文是 FE 3.0 的体验、系统关系、职责边界与设计红线真源。可执行数值、公式、时序、持久化和联机合同见 `GAME_DESIGN_SPEC.md`。

## 1. 设计目标

FE 3.0 将“万物分馏”定义为一套被重新发现的生命型工业，而不是原版制造配方的随机翻版。

玩家的核心体验是：

- 在宇宙中寻找古文明留下的禁忌技术，并逐步理解它的用途。
- 通过解析未知方向发现配方，而不是在开局看到完整目录。
- 为多输入、多输出、矩阵供养和生命塔耐久建立可持续自动化。
- 用更复杂的产线换取原版路线无法提供的资源增殖、原胚繁育与部件回收。
- 随着全局成长，重构既有产线以取得更高吞吐和更小占地。

设计优先做减法。研究、探索、生产和科技已经能够表达的进度，不再包装成独立任务、成就、领奖或额外货币系统。高级内容必须提供明确生产价值和工程选择，不能只靠倍率或内容数量证明存在价值。

## 2. 世界观与开局

古文明曾研究具有维生、繁育和重构能力的生命型工业，其失控与黑雾异常有关。COSMO 主脑无法直接提供这条被禁止的技术路径；玩家只能通过遗物、解析和自身工业重新建立它。

新存档的出生星上会生成一个永久首遗物信号。它是唯一由 FE 自动建立导航的探索点，用于确保玩家无需先获得高级探测能力即可开始模组主线。抵达后，玩家建立分馏亚空间网络，取得两种基础塔、通用原胚、初始研究方向和基础配方。

首遗物只提供启动条件，不保证直接取得全部高级塔。玩家仍需解析方向、发现培育配方，并通过后续探索或黑雾战斗持续补充通用原胚。第一次发现某类高级塔的配方时，古文明档案会恢复一座该类原型，供玩家启动相应产线；其后的常规量产依赖原胚培育。

对已经完整体验过 FE 3.0 的本地档案，新存档采用更快进入高堆叠物流的成长路线，并给予与该路线匹配的物流启动补给。旧版存档不会伪装成已完成 3.0。

## 3. 五塔工业

FE 3.0 固定采用两座基础塔和三座高级生命塔。

| 塔型 | 定位 | 取得与成本 |
| --- | --- | --- |
| 基础矿物塔 | 自动识别普通自然资源并进行同物增殖 | 制造台制作；接入电网 |
| 基础解析塔 | 消耗已取得资格的物品，推进随机内容发现 | 制造台制作；接入电网 |
| 高级矿物塔 | 用珍奇矿物催化普通资源，增殖对应珍奇资源 | 原型发现后由原胚培育；矩阵供养 |
| 高级交互塔 | 培育高级塔，并用高级塔模板繁育通用原胚 | 原型发现后由原胚培育；矩阵供养 |
| 高级转化塔 | 对燃料或机器进行置换重构，并回收被替换部件 | 原型发现后由原胚培育；矩阵供养 |

基础塔保持单输入、自动识别、不选择配方的低操作门槛。它们的正面接口还可连接分馏亚空间，作为低吞吐、无额外传输能耗的上传入口。

高级塔先选择已发现配方，再从任意输入端接收反应物和矩阵。它们支持多输入、多输出，并故意要求玩家处理混带比例、旧物排空、失败物回流和多个产物竞争出口等工程问题。无关物品不会被吞掉；换配方时，旧输入和旧产物优先排出。

矩阵是高级塔的食物，不是配方原料或科研货币。更高层矩阵提供更多营养和更高处理速度。高级塔不接入电网：工作和待机都会消耗营养，长期断粮会损失耐久并最终损毁；营养充足时可以缓慢恢复耐久。建造无人机不能维修生命塔，主动拆除会返还缓存，战斗损毁则不会。

分馏结算使用批量期望取整，保证长期统计符合设定概率，同时避免为高流量逐件随机。失败轮的普通反应物进入流动输出；低概率消耗物继续留在塔内，直到实际发生消耗。所有产物先进入塔内缓存，再按库存权重公平争取输出机会。

## 4. 研究与发现

FE 3.0 将成长分为两种性质明确的研究：

- 随机内容发现：玩家知道自己正在解析哪一种物品方向，但在完成前不知道会得到该方向中的哪项配方或塔特质。
- 确定性成长科技：玩家开始研究前知道具体能力和成本，直接使用原版矩阵在科技树中完成。

探索授予的是“某物品可以被解析”的资格，而不是具体配方。玩家把该物品送入基础解析塔后，成功判定只推进该方向当前最低未完成层级。一个方向可以包含多个内容，同一内容也可以出现在多个方向；内容一旦在任意方向发现，便从所有池中移除，不会重复发现。

配方产物会自然开放后续解析方向，使生产成果继续推动研究。研究页只显示已经取得资格的方向、真实进度和已发现内容，不提前泄露未知池，也不提供领取或研究按钮。

高级塔特质属于各塔自身的最终解析层。玩家必须先取得对应高级塔，再投入大量塔体进行解析；发现特质后，才可研究该特质的确定性五级科技。高级塔直接上传到亚空间时会被献祭并转化为 Memory；投入基础解析塔则只推进特质研究，两条用途互不重复结算。

Frag 是特殊解析物。它不推进配方进度，而是尝试生成额外探索信号。黑雾提供 Frag 和通用原胚的可选补充来源，但无黑雾存档仍可通过定时信号与资源藏点完整推进主线。

## 5. 探索

除首遗物外，遗物与资源藏点统一表现为“古文明信号”。信号永久存在，允许同时积累多个，直到玩家抵达并回收。

探索信息刻意保持不完整：面板只公开目标星球和玩家到达该星球后的信号强度，不公开精确坐标、内容类型或方向箭头。玩家需要在地表根据强度自行搜索。FE 只为首遗物设置一次导航；如果玩家之后手动改选导航，FE 不会覆盖或清除玩家选择。

可生成范围随玩家实际航行能力扩大：先是出生星，再是出生星系，最后是其他星系。更远的信号提供更高价值，但每颗星球拥有有限点位额度，避免无限刷新同一地点。可达范围没有剩余额度时，定时生成暂停，而不是吞掉一个完整周期。

点位内容在抵达时直接结算：研究资格进入解析系统，资源写入亚空间，并用短暂悬浮文字反馈结果。探索奖励可以突破亚空间常规容量，避免远程发现因库存已满而丢失。

每次发现研究内容只提前当前下一次定时信号，不永久修改基础周期。探索信号成长科技独立缩短定时周期并提高 Frag 掉落；两种加速共同保留最低等待时间。

## 6. 亚空间与物流

分馏亚空间是唯一一套宇宙通用库存。它不与某颗星球绑定，也不是第二个随身背包。每种物品拥有独立容量，不竞争共享总空间；扩容科技统一提高所有物品的容量。

玩家可以在主面板手动存取已接入网络的物品。手动存取和基础塔正面上传不额外耗能。普通上传达到该物品容量后会拒收，且不会先取走再丢失货物；探索奖励是唯一允许突破常规容量的正式入口。

行星与星际物流交互站负责自动交换站内库存和亚空间库存。它们保留每槽传输模式、容量模式、阈值、增产点及蓝图/复制粘贴行为。传输按物品价值和实际搬运数量消耗站内电量；电量不足时只搬运可支付的部分，亚空间存取能效科技降低该成本。

上传高级塔不是普通入库操作，而是明确的献祭：塔体消失并记入一个 Memory。其他物品按真实数量和增产点进入亚空间。

## 7. 成长科技

确定性成长科技位于原版科技树第二页，并使用原版各层矩阵。它们包括：

- 全局货物堆叠：同步影响分馏塔、分拣器、物流交互站、研究站等既有堆叠入口，并按堆叠反比缩短原版配方耗时。
- 亚空间扩容：提高每种物品的独立容量。
- 亚空间存取能效：降低物流交互站访问亚空间的电力成本。
- 探索信号增幅：缩短定时信号周期，并提高黑雾 Frag 掉落率。
- 三类高级塔特质：分别降低珍奇催化损耗、提高原胚繁育额外产出、提高置换回收量。

普通存档从原版集装物流阶段进入 FE 堆叠成长。已经完成过 FE 3.0 的本地档案从早期矩阵阶段开始五档成长。路线归属写入当前存档，联机参与者看到相同科技原型与主机决定的同一路线。

当一个真正的 3.0 存档已经取得三类高级塔并达到全局最高堆叠时，本地档案才记录“已经完整玩过 FE 3.0”。这不是成就奖励系统，只用于以后新存档选择成长起点。

## 8. 操作与反馈

FE 主面板保留两种窗口外壳，但共用同一页面注册和业务状态。现役页面包括文明研究、遗物探索、亚空间仓储、开发日记和杂项设置。

文明研究页同时承担研究方向、进度、已发现内容和配方图鉴。遗物探索页只展示搜索所需的信息。亚空间仓储页负责库存查看与手动存取。旧协议恢复、远古科技树、成就、独立分馏配方和原版配方强化页面不再作为 3.0 入口。

高级塔沿用原版分馏塔窗口，只增加配方选择和当前营养显示。耐久继续使用原版建筑耐久表现，不增加独立耐久条、多缓存详情面板或领奖弹窗。

解析发现、探索回收和关键状态使用短暂悬浮文字反馈。教程以五篇现役指南说明开局、亚空间、基础塔、高级生命塔和物流交互站，并保持与 Genesis Book、Orbital Ring 教程布局的兼容。

## 9. 存档、迁移与联机

FE 3.0 使用新的自有存档代际。研究、探索、亚空间、高级塔实例、成长路线、配方统计、UI 和物流交互站状态分别由稳定命名块保存；持久身份使用稳定配方 ID、原型 ID和枚举数值，不依赖 C# 文件名或类名。

FE 2.x 存档只迁移原版持久容器中的物理物品、模型和配方引用，使能够对应的旧塔、建筑和蓝图继续解析。旧协议、成就、科技点、塔等级及其他 2.x 自有进度不映射为 3.0 玩法。过渡存档代际同样不会被解释成正式 3.0 状态。

Nebula 采用主机权威：主机结算研究、探索、亚空间库存、高级塔反应与成长状态；客户端只提交受限请求并接收快照或合法增量。探索认领依据主机记录的对应玩家星球与位置，不接受客户端自报坐标作为权威事实。中途加入玩家会收到当前文明、库存与高级塔状态。

高级塔选定配方和真实缓存随存档与联机同步；选定配方通过稳定整数 ID 进入蓝图与复制粘贴路径。不存在或塔型不匹配的 ID 必须被拒绝或归零。

## 10. 兼容与边界

现有第三方模组兼容以不改变 FE 3.0 核心职责为前提保留。Genesis Book 与 Orbital Ring 可以调整科技位置、物品语义或教程解析，但不能建立第二套研究、亚空间或塔状态真源。Nebula 只承载同步，不拥有业务规则。

原版自然资源分类决定基础矿物塔候选，工业制品不会因为被探索或取得而变成可复制资源。高级转化只覆盖明确用途关系中的少量关键燃料和机器置换，不把所有原版制造关系扩展成通用转换网。

内部 `DataCenter` 名称、旧中文常量和旧物理 ID 可以作为兼容实现继续存在；玩家可见术语统一为“分馏亚空间”“亚空间仓储”和五座现役塔。兼容别名不得重新暴露旧玩法。

## 11. 设计红线

FE 3.0 不得重新引入以下内容：

- 独立协议检索、完整度购买、远古科技点、主路锁定或副产物弃置。
- 正式成就、任务领奖、每日循环、商店、市场、抽奖或 VIP 成长。
- 定向原胚、随机培养、谱系分化、返祖协议或高级解析塔。
- 以黑雾样本阻塞主线，或让无黑雾存档缺失正式内容。
- 为高级配方增加没有独特价值的同质倍率路线。
- 向普通探索信号泄露精确坐标、内容类型或自动方向导航。
- 用单机客户端状态替代主机权威，或用类名充当持久化身份。
- 在高级塔窗口重复制造台式缓存面板、额外状态条和不必要的操作层级。

新增内容必须先证明它服务于探索、解析、生命供养或独特工业重构中的至少一项真实选择，并且不会建立与现有系统重复的成长真源。
