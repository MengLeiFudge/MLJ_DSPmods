# Fractionate Everything 设计结论

本文面向作者和 AI 维护者，只记录 FE 当前稳定的设计方向、职责边界和禁区。公式、概率、状态字段、代码入口和 UI 细节见 `DESIGN_DETAILS.md`。

## 1. 模组定位

FE 的核心是把原版重氢分馏的单输入概率加工模型扩展到更多物品，并以远古文明科技探索组织这些配方。

- 主线服务原版游戏流程，只加快和重构生产，不跳过原版关键阶段。
- 玩家最终可以在单存档中恢复全部核心协议；随机性只改变发现顺序和恢复节奏。
- 概率结果必须能被自动化规模吸收，不能依赖限时、每日次数、付费式卡池或长期重复抽取。
- 旧文明提供研究方向和生产协议，玩家仍需建设真实产线完成解析与生产。

## 2. 四类分馏塔

四类塔与四类配方职责保持稳定：

- 交互塔：培养原胚、执行实体塔返祖、上传物品并连接数据中心。
- 资源塔：复制可持续消耗的原矿资源，不是万能复制塔。
- 转化塔：承载同一工业链或用途链中的便利性转换。
- 解析塔：把矩阵转化为实体解析数据，为协议检索提供输入。

塔型和输入物品共同唯一确定配方。不能因为某类配方数量较多，就按数量机械拆出更多塔型。

## 3. 文明解析主线

文明解析主线由六色矩阵阶段、协议恢复和远古科技树组成。

- 六色矩阵只决定阶段资源和分支门槛，不改变四条塔型主干结构。
- 解析塔输出对应矩阵阶段的实体解析数据。
- 上传解析数据会积累检索机会；每次检索可能失败、发现新协议或推进已发现协议。
- 协议首次发现后允许设置优先目标，但不能完全消除随机发现。
- 协议完整度达到 100 后，对应配方才可运行。
- 阶段内主协议全部完成后，该阶段可进入深层解析并产出远古文明科技点。

禁止恢复 S/A/B/C 稀有度、十连、出金动画、限时池、每日次数、登录奖励或错过不返内容。

## 4. 配方与阶段边界

- 资源复制和工业转化配方由文明协议控制。
- 建筑培养和矩阵解析属于基础设施配方，不进入随机协议池。
- 配方阶段按其产物首次参与原版流程的阶段判断；不可自动采集的木材、植物燃料归电磁阶段。
- 可燃冰允许进入能量阶段；必须依赖星际航行的其他珍奇矿物不得提前。
- 黑雾资源只有在玩家实际接触对应掉落后才可进入协议池；当前作为附属协议，不阻塞六阶段主线完成。
- 能提前提供便利的配方不得让玩家绕开关键原版科技、量产或物流阶段。

配方变体、新供应链和打包物只在基础配方分类稳定后逐族评估，不能为了复杂度批量新增一套镜像物品。

## 5. 远古科技树

科技树只使用一种“远古文明科技点”。复杂度来自分支选择，不来自多种点数。

- 四条稳定主干分别对应交互塔、资源塔、转化塔和解析塔。
- 主干承载塔型通用能力和核心特质；模组、配方族和配方变体放在主干外分叉。
- 分叉可以要求基础协议完成、阶段协议完成、原版科技掌握或生产条件达成。
- 关键节点允许高于普通节点的科技点价格。
- 当前存档最终可以取得全部方向；前中期有限点数只决定优先顺序。

通用能力按塔型共享解锁状态，同类所有实体塔生效；实体级开关仍保存在单个建筑上。

## 6. 成就

成就是单存档固定里程碑，不消耗科技点。

- 条件由真实生产、协议恢复、阶段完成和科技投入自然推动。
- 完成后自动生效，可以定向增强配方族或提供轻量全局加成。
- 成就节点和科技节点彼此独立，不把任务强行挂到科技树上。
- 普通成就不跨存档提供决定性强度。

## 7. 原胚与开局闭环

- 通用原胚主要来自开采装饰物、异常信号、探索事件等非自动化入口。
- 通用原胚可随机培养为四类塔；定向原胚只培养对应塔。
- 实体塔返祖只产生对应定向原胚。
- 开局必须提供足够多的通用原胚，确保随机结果不会阻断第二座交互塔和首座解析塔。
- 遗迹只要求玩家手动重建交互塔，其他建筑保持可观察的完整运转结构。

首轮教学必须让玩家看到“培养出第二座交互塔，再把第一座塔的正面产物接入第二座塔正面完成上传”的闭环。

## 8. 运行架构

文明域拥有定义、状态、检索、科技和成就业务；分馏热路径不直接依赖文明域。

- 文明状态通过一次运行投影写入配方可用性、配方加成和塔型能力缓存。
- 分馏热路径只读取这些缓存。
- 数据中心上传路由负责区分解析数据、普通库存物品和塔型注册。
- 配方仍使用 `RecipeType + InputID` 作为稳定键。
- 定义不进存档，玩家状态进存档，运行缓存在初始化和导入后重建。

禁止引入事件总线、依赖注入容器或为未来假设建立复杂策略层。

## 9. UI

主面板优先保留长期可用的生产、文明解析、资源、恢复手册、图鉴和设置页面。

- 文明解析提供总览、协议恢复、远古科技树和文明成就四个入口。
- UI 只展示、选择和确认，不直接生成物品或修改分馏结果。
- 旧抽取、成长商店、市场交易和旧线性配方成长已经移除；不得再注册旧页面、旧存档块或兼容迁移入口。

## 10. 全局红线

- 不跳过原版关键阶段。
- 不让随机性决定核心内容是否永久可得。
- 不让自动化规模无限放大一次性抽奖价值。
- 不让 UI、任务或商店替代真实产线。
- 不让文明业务对象进入分馏逐物品热路径。
- 不为每个原版物品复制一套新增中间物。
