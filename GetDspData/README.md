# GetDspData 数据导出

GetDspData 在游戏原型加载完成后导出物品、配方、模型、科技及计算器 JSON。计算器文件位于配置的解决方案目录下 `gamedata/calc json/`。

## FE 生产配方

FE 配方取自 `RecipeManager.WorldviewRecipes`，按稳定身份逐张导出。高级塔的选择器展示原型不重复作为普通制造配方导出；基础解析涉及研究状态，不作为固定生产配方导出。

| 字段 | 含义 |
| --- | --- |
| `ID` / `StableID` | 高级配方使用展示原型 ID，基础配方使用持久 ID；`StableID` 为 FE 稳定字符串身份。 |
| `Factories` | 实际生产塔的物品 ID。 |
| `Items` / `ItemCounts` | 全部输入及每成功轮的期望实际消耗，包含辅料、催化剂的消耗概率。 |
| `InputCountsPerRound` | 各输入每轮必须具备的数量，与 `Items` 同序；不能用期望消耗替代最低投入。 |
| `InputConsumeProbabilities` | 各输入在成功轮中的消耗概率，与 `Items` 同序。 |
| `Results` / `ResultCounts` | 每成功轮的平均产出，包含置换回收产物及繁育产物。 |
| `SuccessRatio` | 未加献祭增益的每轮成功率；失败的主料侧流，不计为实际消耗。 |
| `RequiresFood` | 高级塔需要额外矩阵供养；矩阵食物不混入反应原料。 |
| `TimeSpend` | 分馏配方保留 `0` 标记，不代表瞬间完成；吞吐由流量、集装、供养和塔状态决定。 |

消耗率与产出量复用 FE 运行公式，采用导出时的特质等级；启动时导出通常为未研究状态。增产按未喷涂处理，高级配方不声明普通制造增产能力。消费端必须处理多输入与供养条件，不能将旧版单输入分馏算法直接用于高级塔机数计算。

`Factories=[0]` 是既有格式中的虚拟伊卡洛斯来源。具有 FE 高级生产配方的物品，不会仅因缺少普通制造配方就被归入该来源。
